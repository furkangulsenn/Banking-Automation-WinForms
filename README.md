# 🏦 BankApp

![C#](https://img.shields.io/badge/C%23-Programming-blue)
![.NET](https://img.shields.io/badge/.NET-Framework-purple)
![SQLite](https://img.shields.io/badge/Database-SQLite-green)
![Status](https://img.shields.io/badge/Status-Active-success)

BankApp is a basic banking automation system developed using Windows Forms and SQLite.

## 🚀 Features

- Admin Login
- Customer Login
- Create Customer
- Deposit Money
- Transfer Money
- SQLite Database Integration

## 🛠 Technologies Used

- C#
- Windows Forms (.NET Framework)
- SQLite
- Visual Studio 2022

## 📌 Project Status

This project is under development. New features and improvements will be added in future versions.
